# Myth-GRT-AI-World-Simulation
AI-Genereated Simulation Game 
Created by: Marc Jenkins (Nova)
Role: AI Systems Architect | LLM Pipeline Designer | Product Owner

Overview
Myth GRT (Generative Resonant Transformer) is an AI-powered simulation engine where worlds evolve based on the Laws of Becoming, Genre Systems, and dynamic storytelling. Players shape reality using the power of language ("breaths"), breathing life into ever-changing worlds infused with AI-driven mythos.

This system blends LangChain pipelines, fine-tuned LLMs, and modular world-building logic to create fully interactive, evolving universes. Choose your world’s genre (Horror, Comedy, Fantasy, Sci-Fi, and more), and watch it transform through your words.

Core Features
AI-Driven Simulation Engine using LangChain & Transformers

Genre System: Craft unique worlds with distinct narrative tones

Sacred Laws: Resonance, Balance, Irreversibility & more guide gameplay

Persistent World State: Dynamic JSON saves track evolving worlds

Lineage Creation: NPC civilizations with AI-defined sacred purpose

Fine-Tuning Ready: Modular code built for custom LLM expansion

What's Included
myth_grt_engine.py – Core game engine

primordial_mind.py – AI handler (you can link to OpenAI or a fine-tuned LLM)

requirements.txt – Python dependencies

/readme_samples/ – Sample game transcripts

world_state.json & codex_log.txt – Auto-created during gameplay

Watch as the AI transforms your breath into living, responsive world updates.
